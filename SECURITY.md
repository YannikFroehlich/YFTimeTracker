# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils aktuelle stabile Version von
YFTimeTracker bereitgestellt. Ältere Versionen erhalten grundsätzlich keine
separaten Sicherheitsupdates. Bitte prüfen Sie vor einer Meldung, ob das
Problem auch mit der neuesten veröffentlichten Version auftritt.

## Sicherheitslücke vertraulich melden

Bitte veröffentlichen Sie vermutete Sicherheitslücken nicht als öffentliches
GitHub-Issue. Verwenden Sie stattdessen die Funktion
[„Report a vulnerability“](https://github.com/YannikFroehlich/YFTimeTracker/security/advisories/new),
damit Details bis zur Behebung vertraulich bleiben.

Eine hilfreiche Meldung enthält nach Möglichkeit:

- die betroffene YFTimeTracker-Version,
- eine verständliche Beschreibung der Schwachstelle und ihrer Auswirkungen,
- nachvollziehbare Schritte zur Reproduktion,
- betroffene Dateien oder Komponenten und
- mögliche Abhilfen, falls bereits bekannt.

Übermitteln Sie keine echten Zugangsdaten, Tokens oder anderen Geheimnisse.
Falls solche Daten betroffen sind, ersetzen Sie sie durch eindeutig erkennbare
Platzhalter.

Die Meldung wird geprüft und über das private GitHub-Advisory koordiniert. Eine
öffentliche Bekanntgabe sollte erst erfolgen, nachdem eine Korrektur verfügbar
ist oder ein gemeinsamer Veröffentlichungszeitpunkt vereinbart wurde.
