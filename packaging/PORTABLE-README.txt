YFTimeTracker 0.1.0 - Portable Ausgabe fuer Windows 11 x64
================================================================

INSTALLATION

1. Das ZIP-Archiv vollstaendig in einen beliebigen Ordner entpacken.
2. YFTimeTracker.App.exe starten.
3. Optional in der App unter Einstellungen den Windows-Autostart aktivieren.

YFTimeTracker ist selbstenthaltend. Eine separate .NET-Installation ist nicht
notwendig. Die Dateien im entpackten Ordner muessen jedoch zusammenbleiben.

WICHTIG

- Diese Ausgabe ist nicht digital signiert. Windows SmartScreen kann beim ersten
  Start eine Warnung anzeigen.
- Beim Schliessen des Fensters laeuft YFTimeTracker standardmaessig im Infobereich
  der Taskleiste weiter. Zum vollstaendigen Beenden das Tray-Menue verwenden.
- Daten, Einstellungen, Logs und Backups liegen unabhaengig vom Programmordner
  unter %LocalAppData%\YFTimeTracker.

DEINSTALLATION

YFTimeTracker im Tray beenden und anschliessend den entpackten Programmordner
loeschen. Sollen auch alle lokalen Trackingdaten entfernt werden, kann danach
%LocalAppData%\YFTimeTracker manuell geloescht werden.
